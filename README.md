# Buet Cse Alumni

I want to build a website for BUET CSE Alumni Association. 

Website Specifications are the following. 

Home page 

Member Directory: Batchwise members, name, photos, email address, professional information 

Member Web Portal

Do we consider everyone to be a member of BCA? 

Members can receive an email, and personal account page. 

Latest News & Events

Volunteer: Workshops, Community Programs, Campus Arts & History

Stories: Blogs, Travel, Reunions, Magazines

Connect: Registration to Global Alumni Network, Find a Club, Regional Groups, Ask for a Referral

Research & Publications, Projects, Awards and Grants

Career Opportunities: Benefits: Alumni Mentoring, Professional Development

Job posting sharing 

University job opportunities, research assistant or teaching assistant, PhD Students – this can be a member only feature.

Payment Integration: Donation, Picnic fund collection, Souvenir

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone https://github.com/masudias/buet-cse-alumni.git
cd buet-cse-alumni
npm i
npm run dev
```
